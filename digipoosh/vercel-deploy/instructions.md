# بعد از Deploy، این URL رو بذار تو dp-config.js:

window.DP_CONFIG = {
  // ...
  useWorker: true,
  workerUrl: 'https://digipoosh-ai.vercel.app',  // URL واقعی رو بذار
  // ...
};
```

---

## 🎯 **مزایا:**

```
✅ هوش واقعی (Gemma + Groq + OpenRouter)
✅ کاربر بدون فیلترشکن
✅ کلیدها امن (Environment Variables)
✅ رایگان (۱۰۰GB/ماه)
✅ سرعت بالا
✅ بدون نیاز به Token
✅ بدون نیاز به Deploy پیچیده
```

## ⚠️ **نکات:**

```
⚠️ Vercel ممکنه برای ایران تحریم باشه!
   → اگه نشد، از Render.com استفاده کن
   → یا Railway.app

✅ ولی برای کاربر ایرانی مشکلی نیست
   → چون URL از Vercel، نه از ایران
```
