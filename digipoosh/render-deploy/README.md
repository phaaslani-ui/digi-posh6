# 🤖 DigiPoosh AI - Render.com

## 🚀 Deploy:

1. Push to GitHub
2. render.com → New Web Service
3. Connect repo
4. Root: `render-deploy`
5. Build: `npm install`
6. Start: `npm start`

## 🔑 Environment Variables:

- `GEMINI_API_KEY`
- `OPENROUTER_API_KEY`  
- `GROQ_API_KEY`

## 📡 Endpoints:

- `GET /api/health`
- `POST /api/chat`
- `GET /api/trends`
