# 🤖 DigiPoosh AI

دستیار هوشمند مد و استایل فارسی - پروکسی AI برای سایت دیجی‌پوش

## 📋 Endpoints:

- `POST /api/chat` - چت با AI
- `GET /api/trends` - ترندهای روز
- `GET /api/health` - چک سلامت

## 🔑 Environment Variables:

در Settings → Variables تنظیم کن:
- `GEMINI_API_KEY`
- `OPENROUTER_API_KEY`
- `GROQ_API_KEY`
